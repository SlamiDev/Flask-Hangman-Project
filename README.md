# Flask-Hangman-Project
A hangman game for a half-term homework at Kimberly 16-19 Stem College.

In order to play it, first download the pip library by running the following command:

-- pip install Flask

Afterwards, open the main.py file and run it - a link should open up in the console that you can press on. If not, head to http://127.0.0.1:5000 on your browser (localhost:5000) 
Inside of the main.py file, on line 11, you can toggle between two different word sets. Either "WordList.csv" or "LargeWordList.csv". Custom files will work too, just make sure they are in the following format: have a word per line, and contain no symbols or complex characters (unless you want these characters to be added into the guessing pool)
